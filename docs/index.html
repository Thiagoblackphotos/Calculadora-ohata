Classe Calculadora

Classe responsável por realizar cálculos matemáticos básicos para o FinançApp. Esta versão passou pelo processo de refatoração para melhorar a legibilidade.

Autor: Thiago Andrade

Versão: 2.0

Métodos

public double calc(int valorA, int valorB, String operacao)

Executa uma operação matemática básica entre dois números inteiros.

  • valorA: O primeiro número.
  • valorB: O segundo número.
  • operacao: O operador matemático (+, -, *, /).

Retorna: O resultado da operação como um número de ponto flutuante (double).

Lança: ArithmeticException (se houver divisão por zero)

Lança: IllegalArgumentException (se a operação for inválida ou nula)
